# Inhouse 与 BCI-IV2a 实验结果汇总

记录日期：2026-09-11，已更新直接80/20对照。本文汇总旧本地五折、服务器精简消融、64%模型选择配对及直接80%训练的预处理对照。所有百分比均为准确率；差值用百分点（pp）。

目前支持的结论：

- Inhouse本次消融中，关闭增强、加深EEGNet的trial成绩较高；MIL和whole在当前训练/选轮规则下表现较低。
- BCI-IV2a上whole平均成绩最高；MIL对Raspy有改善，对常规EEGNet没有显示一致改善。
- 在固定旧MNE-BIDS清洗、相同训练数据的配对实验中，测试集参与模型选择使合并trial成绩从63.83%变为67.23%，增加3.40pp。
- **现已完成直接80%训练、固定60轮的预处理对照：旧流程68.51%，新流程62.98%，旧流程高5.53pp。** 同旧流程下，测试选择为70.21%，比固定60轮高1.70pp。详见[当前对照结果](INHOUSE_COMPARISON.md#正式结果)。

所有新实验均只使用一个固定训练种子；Inhouse只有一个被试，五折不是五个独立被试。以下结果用于初步判断，不宣称统计显著性或普遍最优。

## 2. 主指标与旧本地五折

主trial指标始终为：同一trial的每个窗口先softmax，平均31个窗口的四类概率，再argmax。它不是硬投票，也不是先平均logits再softmax。whole模型直接评估一个完整4秒片段。

| 指标 | 旧本地Inhouse五折 | 服务器精简实验Raspy-window |
|---|---:|---:|
| Window准确率，合并所有测试窗口 | 54.40%（3963/7285） | 49.03%（3572/7285） |
| Trial概率平均，合并五折测试trial | 69.79%（164/235） | 59.57%（140/235） |
| Trial硬投票 | 68.94%（162/235） | 56.60%（133/235） |

因此69.79%→59.57%的10.21pp变化**不是投票机制换了**。旧、新实验还同时改变了预处理、具体五折成员、训练批次、增强呈现和模型选择协议，不能将差距单独归因于其中一项。

旧本地结果的最终验证折参与了早停和checkpoint选择，且ICA等清洗在session级、分折前进行。旧五折等权trial均值约69.66%；本文统一采用235个trial合并后的69.79%，不混用这两种汇总口径。

数据：[旧结果快照](results/2026-09-11/legacy_summary.json)。

## 3. Inhouse：完整五折精简消融

采用新实验包的训练侧拟合预处理；先对237个原始trial划分，再处理、剔除。本次每种配置合并五折均保留235个测试trial，共同测试交集也是235个，以下差异不是保留样本数量不同造成的。

一个训练种子42；strict内部选轮后重新初始化并在完整外层训练部分重训；选轮上限60轮。本次40项均未触及上限。Window训练按trial组织batch，默认8个trial副本/批；matched增强预算固定每trial每epoch呈现5次，关闭增强仍保留呈现预算。

| 配置 | 合并Trial准确率 | 相对Raspy基准 |
|---|---:|---:|
| Raspy-window基准 | 59.57% | — |
| 常规EEGNet-window | 58.72% | −0.85pp |
| 常规EEGNet＋2个额外block | 62.98% | +3.40pp |
| Raspy-MIL | 34.04% | −25.53pp |
| Raspy-whole | 22.55% | −37.02pp |
| Raspy关闭增强 | 63.83% | +4.26pp |
| Raspy关闭ICA | 59.57% | 0.00pp |
| Raspy关闭CSD | 59.57% | 0.00pp |

### 需要结合训练记录解释的现象

- **关闭增强不是“没有影响”**：本次成绩提高4.26pp。它比较的是新流程增强开/关，没有直接比较旧、新增强生成和呈现方式；单种子不能证明默认增强一般有害。
- **ICA消融没有形成实际去成分对照**：基准五折的ICA排除列表均为空，关闭ICA后五折预测logits逐项完全一致。不能据此断言ICA无用，也不能把“没有检测到成分”理解为“没有眼动伪迹”。
- 关闭CSD与基准总准确率相同，不代表逐trial预测或信号相同。
- MIL五折最终重训轮数为2、1、1、17、1；whole为1、1、2、2、2。低分与当前内部验证选轮非常早同时出现，尚不能把问题直接归结为模型表达能力；也不是60轮上限截断所致。

数据：[逐任务成绩](results/2026-09-11/inhouse_runs.csv)、[选轮审计](results/2026-09-11/inhouse_training_audit.json)、[完成度](results/2026-09-11/inhouse_completion.json)。

## 4. BCI-IV2a：九被试模型与训练目标比较

每位被试用自己的T session训练、E session测试，不是跨被试训练。预处理和增强固定，比较Raspy与常规EEGNet各自的window/MIL/whole；strict内部选轮及重训，seed42，选轮最多60轮。所有配置保留全部2,592个外层测试trial。下表是九位被试等权平均。

| 模型 | Window训练＋trial概率平均 | MIL训练＋trial概率平均 | Whole训练 |
|---|---:|---:|---:|
| Raspy | 58.99% | 63.81% | 68.02% |
| 常规EEGNet | 64.93% | 63.12% | 69.75% |

配对到同一被试后：

| 比较（后者减前者） | 平均变化 | 提高 / 持平 / 降低的被试数 |
|---|---:|---:|
| Raspy-window → 常规EEGNet-window | +5.94pp | 8 / 0 / 1 |
| Raspy-window → Raspy-MIL | +4.82pp | 8 / 0 / 1 |
| 常规EEGNet-window → 常规EEGNet-MIL | −1.81pp | 4 / 0 / 5 |
| Raspy-window → Raspy-whole | +9.03pp | 7 / 0 / 2 |
| 常规EEGNet-window → 常规EEGNet-whole | +4.82pp | 6 / 1 / 2 |

两项触及60轮选轮上限：A05常规EEGNet-window、A08 Raspy-window；两者最终按选出的53轮重训。其余52项正常早停。跨被试差异较大，不能只凭整体均值断言每个人都受益。

数据：[逐被试/配置成绩](results/2026-09-11/bci2a_runs.csv)、[选轮审计](results/2026-09-11/bci2a_training_audit.json)、[完成度](results/2026-09-11/bci2a_completion.json)。

## 5. 旧、新预处理到底差在哪里

两套都包含1–40Hz滤波、平均参考、基线校正、Picard ICA（10成分、decim=2）、500μV幅值拒绝、CSD和RMS，但不是只改变一个拟合scope。

| 环节 | 旧流程 | 新实验流程 |
|---|---|---|
| 实现 | MNE-BIDS-Pipeline，旧MNE 1.8 | 自定义编排MNE函数，服务器MNE 1.11 |
| 滤波 | 连续session滤波后分段 | 每trial及其上下文独立滤波，边界处理不同 |
| ICA拟合 | 每session拟合，发生在分折之前 | 仅在当前训练部分拟合，可跨session |
| ICA伪迹识别 | Pipeline创建眼动相关epochs再检测 | 在训练任务epochs上调用find_bads_eog |
| Inhouse分段端点 | [−2,5]秒，1751点 | [−2,5)秒，1750点 |
| 拒绝与划分 | 先清洗、剔除，再对235个trial分折 | 先对237个原始trial分折，再处理/剔除 |
| CSD | 对清洗后的MNE epochs计算 | 用MNE构建变换矩阵，再逐trial应用；不能仅凭写法断言算法不同 |
| RMS | 原本就是训练折拟合 | 相应训练部分拟合；不是从全数据归一化改为训练侧归一化 |

核对旧三个session的Pipeline日志后，旧流程也没有标记并剔除ICA成分。因此，本次新旧成绩变化不能简单归因于ICA剔除了不同成分。

**后续直接80%训练对照已测得整套预处理差异5.53pp**，见[当前对照结果](INHOUSE_COMPARISON.md#正式结果)。下节3.40pp仍专指先前64%训练下的模型选择差异，不能互换。

## 6. 固定旧预处理后的模型选择配对

直接复用旧MNE-BIDS清洗产物及含CSD的HDF5，并核对来源clean FIF哈希。使用旧235个trial和原五折。两组共享相同实际训练trial、训练侧RMS、窗口/噪声数组、32窗口batch、原EEGNet与训练循环、初始化和sampler随机序列。

每折从外层训练池固定留20%作内部验证，因此实际训练约占全数据64%。两组都不再额外refit，避免混入训练样本数差异。训练种子按42+fold配对；不是旧五折全局RNG连续推进的原样复跑。

唯一主动切换的是选择集来源：

- 内部验证组：由内部验证集window accuracy调学习率、loss选checkpoint和早停。
- 测试选择组：以上操作改用外层测试折；不对测试数据反向传播。

两组最终都在同一外层测试折评估。最大500轮，保留旧10轮不改善早停。五折的初始化、训练输入和第一轮训练loss一致性检查全部通过。

| 折（代码从0计数） | 内部验证选模型 | 测试折选模型 | 差值 |
|---|---:|---:|---:|
| 0 | 77.08% | 77.08% | 0.00pp |
| 1 | 66.67% | 79.17% | +12.50pp |
| 2 | 58.33% | 62.50% | +4.17pp |
| 3 | 58.70% | 58.70% | 0.00pp |
| 4 | 57.78% | 57.78% | 0.00pp |
| **合并235个测试trial** | **63.83%（150/235）** | **67.23%（158/235）** | **+3.40pp** |

在这组固定条件下，测试集参与模型选择增加了8个判对trial。这个差值是一次配对观察，不是总体乐观偏差的无偏估计，也不是通用固定修正量。旧session级清洗仍被固定复用，本实验没有同时消除潜在预处理信息泄漏。

数据：[完整摘要](results/2026-09-11/selection_bias_summary.json)、[五折对照CSV](results/2026-09-11/selection_bias_folds.csv)。运行设计见[配对实验说明](SELECTION_BIAS.md)。

## 7. 四个容易混淆的数字

| 实验 | 预处理 | 训练/选择协议 | Trial准确率 |
|---|---|---|---:|
| 最初本地五折 | 旧MNE-BIDS | 约80%训练，汇报折参与选择 | 69.79% |
| 夜间Raspy基准 | 新逐trial流程 | 内部选轮后在外层训练池重训，独立外层测试 | 59.57% |
| 本次配对：内部验证选择 | 固定旧清洗 | 相同约64%训练，无refit | 63.83% |
| 本次配对：测试折选择 | 固定旧清洗 | 相同约64%训练，无refit | 67.23% |

只有最后两行是本次刻意构造的模型选择配对。不能将63.83%−59.57%=4.26pp解释成预处理收益，也不能用10.21pp减去3.40pp推算剩余因素的贡献。消融中“关闭增强”的63.83%与配对内部验证组的63.83%只是数值相同，不是同一实验。

上述四行是先前实验的结果。后续已取消内部划分，直接80/20训练、固定60轮，完成旧/新预处理对照（68.51%/62.98%），另保留旧流程测试选择组（70.21%）。这些新数字必须按新协议解读，详见[当前对照结果](INHOUSE_COMPARISON.md#正式结果)。
