# 统一旧预处理后的模型选择配对实验

本实验只回答：相同训练数据和训练算法下，把内部验证集换成外层测试折，用于学习率调度、早停和checkpoint选择，会使最终汇报的测试成绩改变多少。

## 统一的部分

- 直接复用原MNE-BIDS-Pipeline产出的清洗结果及旧 `outputs/prepared/clean_trials.h5`（已包含CSD）。CPU准备作业验证三个clean FIF与旧folds.json记录的SHA256一致，再复制并冻结HDF5；不重新调用新逐trial预处理，也不重新执行不同版本的MNE清洗。
- 使用旧235个clean trials及原五折分配，不使用nightly实验的237原始trial分折。
- 每个外层训练池固定留20%作为内部验证。两组的实际训练trial完全相同，约全数据64%；同一外层测试折约20%。
- RMS均只在这一相同的实际训练部分拟合；共享RMS数值、窗口数组和噪声数组。
- 复用原模型、OneHotMSE、Adam、32窗口batch、原窗加4个固定噪声副本、1秒31窗和概率平均trial评估。
- 每折两组使用相同初始化和独立但同seed的训练sampler RNG，避免验证集大小不同额外消耗训练RNG。seed按42+fold固定；与旧五折全局RNG连续推进不同，因此不声称逐位复现历史69.79%。
- 直接调用原 `src/inhouse_bci_raspy/training/engine.py`，不修改原训练循环；最大500轮、10轮不改善早停。

## 唯一主动改变的因素

| 组 | SGD训练数据 | 驱动调度/早停/checkpoint的数据 | 最终评分 |
|---|---|---|---|
| validation_selected | 相同的约64% trial | 内部约16%验证trial | 相同外层测试折 |
| test_selected | 同上 | 外层约20%测试trial | 同一外层测试折 |

两组都不做额外refit，避免把训练数据量和重训步骤加入对照。原训练器以选择集**window accuracy**驱动学习率，以选择集**loss**驱动checkpoint和早停；这里的“偷看test acc”实际包含上述整套选择机制，并非只改一个准确率统计。两组均不对测试数据反向传播。

输出差值定义为 `test_selected - validation_selected`，单位为trial准确率百分点。差值可正可负，不预设“偷看”必然提高每一折准确率。外层五折属于同一被试，不当作五个独立被试做显著性检验。

## 解释边界

本实验固定了历史session级清洗。它能研究**该固定清洗条件下**选择集来源的影响，不能证明不存在预处理信息泄漏，也不能把组间差值直接当成对总体乐观偏差的无偏估计。它没有复现旧80%训练的全部条件；不用于把旧69.79%与新59.57%的全部差距归因到一个因素。

若需要后续严格评估，可以再建立共同的训练侧拟合MNE流程；不要在当前配对中只给一组更换清洗范围。

## 运行与结果

```bash
bash run_selection_bias.sh local   # 仅检查配置/路径
bash run_selection_bias.sh server  # CPU准备 → 单GPU上同时跑2折 → CPU报告
```

配置：`config/selection_bias.json`。默认完整5折，两组共10次训练。输出：`/public/home/hugf2022/inhouse_bci_raspy/selection-bias-v1/`。

每折保存共享输入指纹、trial划分、RMS、初始化指纹、两组历史/checkpoint/窗口预测CSV及NPZ；`pair_verified.json`确认相同初始化和第一轮训练loss。最终报告包含五折配对准确率、pooled trial准确率及百分点差、PNG/PDF配对图和完成度。

脚本保护结果目录和队列锁。重复提交可跳过已完成组；旧训练器没有epoch恢复接口，因此中断的组从初始化重新训练，完成组不覆盖。强杀后遗留锁需核实作业退出再处理。结果依赖源码/环境指纹，不要在作业中途修改相关Python源码。

## 已完成的验证

独立验证配置只取fold0、fold1，每组最多2轮；CPU准备4107518、GPU验证4107519均成功。两折的两组均完成，`pair_verified.json`核对通过。两个合成隔离测试通过：修改外层测试标签不改变内部划分；修改测试信号不改变RMS、训练窗口或内部验证窗口。

CPU准备4107521、GPU训练4107522、CPU报告4107523均成功；GPU耗时11分48秒。五折两组共10次训练完整结束，五折配对一致性检查全部通过。合并235个测试trial，内部验证选择为150/235（63.83%），测试折选择为158/235（67.23%），差值+3.40个百分点；两折提高、三折持平。
